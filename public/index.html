    How it works

    1. Set it up for you

      Choose your language, reading level, text size and colours. This takes under a minute and is remembered on your device.

    2. Speak, type or show

      Ask a question, paste a letter, add a photo, or turn on captions for a conversation.

    3. Get it your way

      Read a short answer, or have it read aloud. Ask again in simpler words as many times as you like.

    Accessibility Statement & Standards Compliance

    Samavesh AI is committed to digital inclusion and is built according to the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA.

    • Full keyboard navigation with visible focus rings across all themes.
    • Support for screen readers via ARIA live regions and semantic landmarks.
    • Dyslexia-friendly typography with custom font spacing and line-heights.
    • Multiple high-contrast themes including Yellow-on-Black and SVG color-blindness simulation filters.
    • Speech recognition in 8 Indian regional languages.

    If you experience any barriers using this website, please report them to us so we can continue improving accessibility for everyone.
